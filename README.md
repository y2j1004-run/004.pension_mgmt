# 004.pension_mgmt — 개인연금 관리

개인연금(연금저축·IRP·DC)을 ETF로 운용하면서 **매달 불입금을 어디에 넣을지 정하고**, 보유 ETF의 흐름과 수익률을 추적하는 개인용 앱입니다.
Android 휴대폰에 설치해 쓰는 PWA(설치형 웹앱)이고, 데이터는 **휴대폰 안에만** 저장됩니다.

> 이 저장소는 public입니다. 보유 종목·금액·백업 파일 등 개인 데이터는 커밋하지 마세요.
> 앱의 계산과 점검은 내가 정한 목표 비중과 입력한 가격 기준의 참고용이며 투자 권유가 아닙니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| 🏠 홈 | 평가금액·넣은 돈·수익률, **연환산 수익률(XIRR)**, 평가금액 vs 원금 추세, 지금/목표 비중, 점검 알림, 올해 세액공제 예상, 다음 불입일 D-day |
| 💰 이번 달 불입 | 입금액 + 예수금 → 현재가 입력 → **살 수량 자동 계산** → 증권앱에서 주문 → 체결 기록 |
| 📈 종목 | **6개월 추세 분석·목표 비중 추천**, 보유 ETF별 평가손익·1개월/3개월/1년 등락·가격 추세, 목표 비중·보수·분류 관리, 새 종목 추가 시 점검 |
| 🧾 기록 | 입금·매수·매도·분배금 내역 (월별), 직접 추가·삭제 |
| ⚙️ 설정 | 계좌 종류, 월 불입액(70만원)·불입일(21일), 세액공제율, 백업·복원 |

## 매달 21일에 하는 일

1. 💰 **이번 달 불입** 탭을 엽니다 (불입일이 지나고 기록이 없으면 탭에 점이 뜹니다).
2. 증권앱에서 보이는 **현재가**를 종목마다 넣습니다 (지난 가격이 미리 채워져 있음).
3. 배분 방식을 고릅니다.
   - **목표 비중대로** (기본): 목표보다 모자란 종목부터 1주씩 — 팔지 않고 불입금만으로 비중을 맞춥니다.
   - **지금 비중대로**: 지금 비율 그대로 늘립니다.
   - **한 종목에**: 고른 종목만 삽니다.
4. 계산된 수량대로 주문하고, 체결가·수량이 다르면 고친 뒤 **기록** 버튼을 누릅니다.
5. 한 달에 한 번 ⚙️ 설정에서 **백업**합니다.

### 기존 종목 vs 새 종목

- 새 종목을 넣고 싶으면 📈 종목에서 추가하고 목표 비중을 줍니다. 다음 배분에서 가장 모자란 종목이 되어 먼저 매수됩니다.
- 추가할 때 **같은 분류를 이미 갖고 있는지**, **보수가 더 비싼지**, 종목 수가 너무 많지 않은지 점검해 줍니다.
- 목표를 0%로 바꾼 종목은 새로 사지 않습니다 (정리 대상).

### 점검 규칙 (홈)

| 점검 | 기준 |
|---|---|
| 비중 이탈 | 목표 대비 ±5%p (설정에서 변경) — 낮으면 우선 매수, 2배 이상 높으면 매도 후 재배분 고려 |
| 집중 | 한 종목이 50% 초과 + 목표보다 높음 |
| 보수 | 총보수 0.3% 이상 |
| 위험자산 한도 | IRP·DC는 위험자산 70% — 배분 계산에서도 넘지 않게 함 |
| 놀고 있는 돈 | 예수금이 월 불입액의 1.5배 이상 |
| 오래된 가격 | 35일 넘게 가격 업데이트 없음 |

### 세액공제 (2026년 기준)

연금저축 연 600만원, IRP 합산 900만원까지 13.2%/16.5%. 월 70만원 = 연 840만원이라 연금저축만으로는 240만원이 한도를 넘습니다.
홈에서 올해 불입액·연말 예상·예상 환급액·남은 한도를 보여줍니다.

### 매일 종가 (자동)

국내 시세 사이트는 브라우저에서 바로 부를 수 없어서(CORS), GitHub Actions가 **평일 장 마감 후(16:47 KST)** 상장 ETF **전체**의
최근 약 6.5개월 종가를 받아 앱 주소의 `prices/`에 함께 배포합니다(`scripts/fetch_prices.mjs`).
전체를 받기 때문에 공개된 파일만 봐서는 누가 어떤 종목을 가졌는지 알 수 없습니다.

- 앱을 열 때(마지막으로 받은 지 3시간이 지났으면) 내 종목의 종가를 받아 기기에 저장 → 평가금액·차트·등락률이 자동 갱신
- 직접 넣은 가격·체결가가 같은 날짜의 종가보다 우선
- 종목 추가 때 코드 6자리를 넣으면 이름·분류 자동 입력
- 공개 저장소의 예약 실행은 저장소에 60일 동안 활동이 없으면 GitHub이 멈춥니다. Actions 탭에서 다시 켜면 됩니다.

### 6개월 추세 · 목표 비중 추천 (`src/calc/trend.ts`)

종목별 6개월·3개월·1개월 수익률, 변동성, 최대낙폭, 추세의 꾸준함(회귀 R²), 같이 움직이는 종목 쌍(상관계수 0.9 이상)을 보여 주고,
**지금 목표 비중에서 출발해** 다음처럼 조정한 비중을 제안합니다.

1. 위험 대비 성과(6개월 수익률 ÷ 변동성)가 다른 종목보다 좋으면 늘리고 부진하면 줄임 — 반영 정도: 조금만 / 보통 / 적극적으로
2. 변동성이 큰 종목은 낮추고 작은 종목은 높임
3. 한 종목 최대 40%, IRP·DC는 위험자산 70% 이하
4. (선택) 3% 미만으로 작은 종목은 정리 후보로 0%
5. 거래일이 40일 미만인 종목(신규 상장 등)은 지금 목표 유지

"추천 비중을 목표로 적용"을 누르면 목표가 바뀌고, 이전 목표는 되돌리기용으로 저장됩니다. 지난 추세가 이어진다는 보장은 없으며 투자 권유가 아닙니다.

### 새종목 추천 (`src/calc/discover.ts`)

매일 받는 ETF 전체의 6개월 종가(`prices/all.json`, 약 1MB — "추천 받기"를 누를 때만 받음)로, 갖고 있지 않은 종목 중 5개를 이유와 함께 추천합니다.

- **제외:** 레버리지·인버스(연금저축 매수 불가), 머니마켓·초단기채 같은 현금성, 거래일 100일 미만, 하루 거래대금 5억원 미만, 갖고 있는 종목과 사실상 같은 지수(상관계수 0.95 이상 — 예: 다른 운용사의 S&P500)
- **점수:** 위험 대비 성과(6개월 수익률 ÷ 변동성), 추세의 꾸준함, 최대낙폭, 내 포트폴리오와 다르게 움직이는 정도 — 추세 우선 / 균형 / 분산 우선에 따라 비중이 다름
- **겹침 방지:** 이미 고른 후보와 상관계수 0.85 이상이면 건너뜀 (반도체 ETF 5개를 추천하지 않도록)
- **사유·주의:** 성과 순위, 추세, 낙폭, 상관계수, 새 분류인지, 거래대금 / 과열(6개월 +60% 초과), 최근 1개월 조정, 큰 변동성
- 총보수·추종 지수·구성 종목은 데이터에 없으므로 운용사 홈페이지에서 확인해야 합니다.

### 장 마감 브리핑 (홈, `src/calc/brief.ts`)

가장 최근 거래일의 결과를 홈 맨 위에 보여 줍니다(평일 16:47 이후 갱신, 다음 날 앱을 열면 확인).

- **내 ETF:** 하루 평가손익(원·%), 5거래일 변화, 가장 크게 움직인 종목과 반대로 움직인 종목, 종목별 등락·손익
- **종목별 특이 사항:** 평소보다 큰 움직임(최근 60거래일 하루 변동의 2배 이상), 6개월 최고·최저가, 3거래일 이상 연속 상승·하락, 20일 평균선 돌파·이탈(1% 이상), 6개월 고점 대비 -15% 이하
- **ETF 시장:** 상승·하락 종목 수, 분류별 중앙값 등락, 많이 오르고 내린 ETF(거래대금 5억원 이상, 레버리지·인버스 제외) — `prices/brief.json`
- **언론 보도:** 정해진 주제(국내 증시, 뉴욕 증시, 반도체, 엔비디아, 구글, 테슬라, 팔란티어, AI 전력 인프라, 금, 금리·채권, 환율, 배당, ETF 시장)별 Google 뉴스 최근 헤드라인 — `prices/news.json` (`scripts/fetch_news.mjs`). 주제 목록이 모두에게 같아 공개 파일로 보유 종목을 알 수 없고, 내 종목과 주제의 연결은 휴대폰에서 이름으로 합니다(`src/calc/news.ts`). 제목·언론사·링크만 보여 주고 기사 본문은 저장하지 않습니다.
- **유튜브:** 참고 채널(현재 없음)의 최근 3일 영상 제목·소개 첫 줄·링크 — 채널의 공개 영상 피드(`scripts/news.mjs`의 `CHANNELS`). 제목이 내 종목의 주제(반도체, 금리 등)를 다루면 "내 종목" 표시. 채널을 더하려면 `CHANNELS`에 채널 ID를 추가합니다.
